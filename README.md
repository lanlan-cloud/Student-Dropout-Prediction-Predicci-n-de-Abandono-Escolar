# 🎓 Student Dropout Prediction | Predicción de Abandono Escolar

---

## 🇺🇸 English Version

## 📌 Project Overview

This project uses Machine Learning to predict student dropout risk based on academic and socio-economic factors.

The goal is to understand which variables influence student retention and how data can support decision-making in education.

---

## 🧠 Objectives

* Predict student dropout probability
* Identify key risk factors
* Apply Machine Learning in a real-world social problem

---

## 🛠 Tools Used

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Google Colab

---

## 📂 Dataset

Source: Education dataset from Kaggle
Includes real variables such as:

* Age
* Grades
* Attendance
* Socioeconomic indicators

---

## 📈 Key Insights

* Academic performance strongly influences dropout risk
* Socioeconomic factors also play a significant role
* Machine Learning can help identify at-risk students early
